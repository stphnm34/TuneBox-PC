# TuneBox-PC
Clean, speed up and check the health of your Windows PC, free and open source.

TuneBox PC puts the maintenance tools Windows hides in different places into one simple dark app. Clean junk files, free up RAM, check your drive's health, temperature and remaining lifespan, see how long your PC has been on and which apps you use most, remove bloatware and ads, block apps you don't want used, and set the PC to shut down automatically when it's left idle.

It's free and open source, uses only tools built into Windows, and asks before doing anything destructive. A restore point can be created before any changes.
